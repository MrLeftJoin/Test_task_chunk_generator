За счет чего достигается ускорение:

-Строки перебираются и сравниваются не в цилке через python, а через библиотеки pandas и numpy,
которые написаны на С (который намного быстрее питона + там используются векторные вычисления)

-Результат подается через yield по чанку, а не всем списком целиком (т.е. "лениво"). Так можно обработать данные любого размера в потоке

-Метод iloc при нарезке строк создает «представление» (view) исходного DataFrame. 
Данные не дублируются в новые объекты памяти, в результат подается «окно», которое смотрит на конкретный участок уже загруженной таблицы.
